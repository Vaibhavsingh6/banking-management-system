# Project Statement

## Title

Banking Management System

## Purpose

This project is a Python command-line application created for the VITyarthi Python Essentials submission. It demonstrates core Python concepts by managing simple bank accounts without using a database or any external library.

## Problem addressed

Keeping account balances and transaction records manually is error-prone. This program provides a small, menu-driven way to create accounts, record deposits and withdrawals, check balances, and view account history.

## Concepts used

- Functions and modules
- Classes and object-oriented programming
- Lists and dictionaries
- File handling with JSON
- Exception handling and input validation
- Loops and conditional statements
- Automated testing with `unittest`

## Working flow

```text
User menu -> CLI functions -> BankService validation/rules -> JSONStorage -> accounts.json
```

## Limitations

The application is intended for learning only. It has no login system, encryption, network access, or connection to a real bank.
